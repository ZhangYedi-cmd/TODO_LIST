# TODO LIST 功能设计（v1）

## 目标
做一个可本地运行、可持续扩展的个人任务管理应用，优先保证：
1. 录入任务快
2. 状态切换快
3. 检索和筛选快

## 用户画像
- 个人开发者 / 小团队负责人
- 需要在一天内高频记录任务、切换优先级、追踪截止日期

## v1 功能范围（必须实现）

### 1) 任务管理（CRUD）
- 新建任务：标题（必填）、描述（选填）、截止时间（选填）、优先级（P1/P2/P3）
- 编辑任务：支持修改以上字段
- 删除任务：二次确认
- 完成任务：支持勾选完成/恢复

### 2) 看板状态流
- 三列：`Todo` / `In Progress` / `Done`
- 支持任务状态切换（至少按钮切换；可选拖拽）

### 3) 筛选与检索
- 关键字搜索（标题/描述）
- 按状态筛选
- 按优先级筛选
- “今日到期 / 逾期”快速筛选

### 4) 数据持久化
- 使用 localStorage 持久化
- 页面刷新后数据不丢失

### 5) 基础体验
- 响应式（桌面优先，移动端可用）
- 简洁视觉层级
- 空状态引导
- 基本错误提示

## 非目标（v1 不做）
- 多用户协作
- 云端同步
- OAuth 登录
- 复杂权限系统

## 技术约束
- Next.js + TypeScript
- 代码可维护，组件划分清晰
- 至少补充核心逻辑测试（状态流转/筛选）

## 验收标准
- `npm run lint` 通过
- `npm run build` 通过
- 主要流程可手动验证：新增、编辑、删除、状态切换、筛选、持久化

## 风险与 downside
- localStorage 方案简单但无法跨设备同步；后续如果要团队协作，需要迁移到后端存储。
